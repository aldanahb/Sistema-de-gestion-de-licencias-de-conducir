
Proyecto para la materia "Métodos Ágiles para el Diseño de Software". El sistema permite gestionar licencias de conducir, usuarios administrativos y titulares. Tiene las siguientes funcionalidades:
* Emisión de licencias.
* Cálculo de vigencia de una licencia de acuerdo a la edad del titular.
* Cálculo de costo de una licencia de acuerdo a la clase de licencia y su vigencia en años.
* Impresión de licencias.
* Renovación de licencias.
* Emisión de copias de licencias.
* Listado de licencias que han expirado.
* Listado de licencias vigentes por criterios (nombre, apellido, grupo sanguíneo, factor RH, donante de órganos).
* Alta de titulares.
* Modificación de los datos de un titular.
* Alta de usuarios.
* Modificación de los datos de un usuario.

Para este proyecto se aplicó la metodología SCRUM y se utilizó Java Spring Boot. Las interfaces se realizaron con HTML, CSS y JavaScript. Para la base de datos se utilizó PostgreSQL.
Se presenta también el documento entregado al profesor, que explica cómo se fue aplicando la metodología.
